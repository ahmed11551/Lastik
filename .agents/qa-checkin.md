# QA & Acceptance Agent — Check-in Tasks (обязательные к возврату)

## Задача 1
Напиши Pest-тест: пользователь Org A не видит заказы Org B через API orders.index и orders.show. Ожидаемо: 200 с пустым списком для A, 403/404 для прямого доступа к B.

## Задача 2
Напиши Pest-тест: двукратный одновременный резерв последней единицы товара → второй запрос падает с InsufficientStockException, без отрицательного available.

## Задача 3
Напиши Pest-тест: оплата после закрытия смены блокируется на уровне PaymentService. Ожидаемо: PaymentCorrectionRequiredException или 409.

## Задача 4
Напиши Pest-тест: после закрытия смены изменение cancelled_at/итогов запрещено. Любая мутация → 409.

## Задача 5
Напиши Pest-тест: добавление позиции в заказ пишет immutable snapshot в order_items.snapshot с ценой/правилом KPI на момент добавления.

## Задача 6
Напиши Pest-тест: изменение карточки товара после добавления в заказ не меняет старый snapshot.

## Задача 7
Напиши Pest-тест: у пользователя не более 2 устройств. Третий девайс отклоняется с 409.

## Задача 8
Напиши Pest-тест: journal append-only — попытка изменить/удалить AuditLog падает с SQL error или 403.

## Задача 9
Напиши Pest-тест: загрузка CommerceML2 остатков не затирает reserved при обновлении actual. Если actual < reserved → запись конфликта и 0 потерь резерва.

## Задача 10
Напиши Pest-тест: открытие смены → можно проводить оплаты; закрытие смены → итоги совпадают с агрегатом payments shift_id=?. Любое расхождение → 409.
