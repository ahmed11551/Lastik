# Frontend Agent — Check-in Tasks

## Задача 1
Предложи структуру директорий фронтенда LASTIK под Inertia + Vue 3 + shadcn/ui. Включи: layouts, pages, components, composables, types, translations. Укажи, как подключить shadcn/ui в Vue 3 в рамках repo.

## Задача 2
Опиши общий Layout: сайдбар/бредкрамбы, header с выбором организации/точки, уведомления, мобильное меню, адаптив до 320px. Сделай явные токены Tailwind под LASTIK, без глобальных внедрений стилей.

## Задача 3
Предложи Login/SelectOrganization/Location screen с валидацией, обработкой ошибок и redirect. Без лишних локальных сторов.

## Задача 4
Предложи страницу Orders: фильтры, быстрый поиск по ФИО/телефону/госномеру/номеру заказа, создание нового заказа, переходы по сценариям. Опиши состояние loading/error/empty.

## Задача 5
Предложи форму создания/редактирования заказа с scenarios: «продажа с установкой» и «продажа без установки». Опиши выбор покупателя, автомобиля, добавление товара/услуги, проверку остатка, резерв, оплату.

## Задача 6
Предложи CashShift экран: открытие смены, ввод инкассации/выемки, отчёт смены, TV-режим. Включи адаптив и состояния закрытия/ошибок.

## Задача 7
Предложи админские экраны: Users/Roles/Permissions, Products/Services, Warehouses/Stocks/Prices, Modules/Settings. Учти права и tenant isolation на уровне UI/формы.

## Acceptance mapping
Для 49.5/49.6/49.7/49.8/44 предлжи, как frontend обеспечивает прохождение сценариев через интерфейс без Postman и ручного SQL: формы, ошибки, обязательные поля, дефолтные состояния.
