## 2. Предмет приёмки
Программный комплекс «AUTOMETRIA ERP» — веб-платформа управления шинным центром, магазином шин/дисков, автосервисными зонами, складом, кассой, сотрудниками, покупателями и заказами.

Передаётся в составе:
- Исходный код (репозиторий, ветка `main`, коммит `9c3bf3c`).
- Документация (папка `docs/` — Сдаточный пакет, Runbook, Архитектура).
- Контейнеризированная среда (Docker Compose: app + nginx + queue-worker + scheduler + PostgreSQL + Redis).
